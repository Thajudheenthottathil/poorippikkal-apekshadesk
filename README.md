## ലഭ്യമായ പ്രധാന സേവനങ്ങൾ (55+ Official Forms & Core Services)

### 1. 🏛️ വില്ലേജ് ഓഫീസ്, പഞ്ചായത്ത് & K-SMART അപേക്ഷകൾ (Official Kerala Petitions)
* വരുമാന സർട്ടിഫിക്കറ്റ്, ജാതി സർട്ടിഫിക്കറ്റ്, നോൺ-ക്രീമിലെയർ, EWS, കൈവശാവകാശ സർട്ടിഫിക്കറ്റ്, പോക്കുവരവ് (Mutation) അപേക്ഷ.
* അപകടകരമായ മരം മുറിച്ചു മാറ്റാനുള്ള പഞ്ചായത്ത് അപേക്ഷ.
* ജനന-മരണ സർട്ടിഫിക്കറ്റ് തിരുത്തൽ, കെട്ടിട നികുതി, ബിൽഡിംഗ് പെർമിറ്റ് അപേക്ഷകൾ.
* റേഷൻ കാർഡ് പേര് ചേർക്കൽ/ഒഴിവാക്കൽ, വാർദ്ധക്യകാല-വിധവാ പെൻഷൻ, CMDRF ചികിത്സാ സഹായ അപേക്ഷ, വിവരാവകാശ (RTI) അപേക്ഷ.

* പോലീസ് സ്റ്റേഷൻ പരാതി മാതൃകകൾ, സർട്ടിഫിക്കറ്റുകൾ/മൊബൈൽ ഫോൺ നഷ്ടപ്പെട്ടാലുള്ള പരാതി, സൈബർ തട്ടിപ്പ് പരാതികൾ, ബാങ്ക് അക്കൗണ്ട്/ലോൺ അപേക്ഷകൾ.
