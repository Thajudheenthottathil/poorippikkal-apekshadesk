## 🛡️ സുതാര്യമായ പ്രവർത്തന രീതിയും സുരക്ഷാ വിവരങ്ങളും (Transparent Architecture & GitHub Security Audit)

1. **വ്യക്തിഗത വിവരങ്ങൾ 100% ഓപ്ഷണൽ (`📝 കാലി ഫോം / Blank Form Mode`):**
   - ഈ വെബ്‌സൈറ്റിൽ നിങ്ങളുടെ പേരോ, വിലാസമോ, ഫോൺ നമ്പറോ നിർബന്ധമായും ടൈപ്പ് ചെയ്യേണ്ടതില്ല. സ്വകാര്യ വിവരങ്ങൾ ഓൺലൈനിൽ നൽകാൻ താല്പര്യമില്ലാത്തവർക്ക് **"📝 കാലി ഫോം (പേന കൊണ്ട് എഴുതാൻ / Blank Form)"** എന്ന ബട്ടൺ അമർത്തി, വിവരങ്ങൾ എഴുതാനുള്ള സ്ഥാനത്ത് ഡോട്ട് ലൈനുകളോടു കൂടിയ (`........................................`) A4 PDF നേരിട്ട് പ്രിന്റ് എടുത്ത് പേന കൊണ്ട് എഴുതി പൂരിപ്പിക്കാം.
2. **ബ്രൗസറിൽ നടക്കുന്നവയും AI സെർവർ വഴി നടക്കുന്നവയും (100% സത്യസന്ധമായ ഡാറ്റാ വിവരണം):**
   - **മോഡ് A — ബ്രൗസറിനുള്ളിൽ നടക്കുന്നവ (Client-Side Templates & `jsPDF`):** വെബ്‌സൈറ്റിലെ 55+ റെഡിമെയ്ഡ് ഫോമുകൾ തിരഞ്ഞെടുക്കുന്നതും, കാലി ഫോം (`📝 കാലി ഫോം`) എടുക്കുന്നതും, പേപ്പറിൽ നേരിട്ട് തൊട്ട് തിരുത്തുന്നതും, `jsPDF` + `html2canvas` ഉപയോഗിച്ച് A4 PDF നിർമ്മിക്കുന്നതും ഉപയോക്താവിന്റെ ബ്രൗസറിനുള്ളിലാണ് നടക്കുന്നത്.
   - **മോഡ് B — ഓപ്ഷണൽ AI സഹായി (`/api/*` Server Endpoints):** ഉപയോക്താവ് സ്വന്തം ഇഷ്ടപ്രകാരം വോയ്‌സ്/ചാറ്റ് വഴി പുതിയ കത്ത് എഴുതിക്കുമ്പോഴോ (`/api/process-request`), ശബ്ദം അക്ഷരമാക്കുമ്പോഴോ (`/api/transcribe-audio`), അപ്‌ലോഡ് ചെയ്ത PDF വായിക്കുമ്പോഴോ (`/api/extract-pdf-content`), AI വിവർത്തനം (`/api/translate-doc`) അല്ലെങ്കിൽ ഹെൽപ്പ് ചാറ്റ് (`/api/help-chat`) ഉപയോഗിക്കുമ്പോഴോ നൽകുന്ന വിവരങ്ങൾ സെർവർ (`server.ts`) വഴി **Google Gemini API** അല്ലെങ്കിൽ **Hugging Face API** ഉപയോഗിച്ചാണ് പ്രോസസ്സ് ചെയ്യുന്നത്.
   - **സെർവർ സ്റ്റോറേജ് നയം (No Database / Zero Disk File Writes):** ഉപയോക്താക്കളുടെ അപേക്ഷകളോ വ്യക്തിഗത വിവരങ്ങളോ സൂക്ഷിക്കാൻ സെർവറിൽ ഡാറ്റാബേസോ ഡിസ്ക് ഫയലുകളോ (`fs.writeFileSync`) ഉപയോഗിക്കുന്നില്ല. (ഉപയോക്താക്കൾ സ്വമേധയാ അയക്കുന്ന ഫീഡ്‌ബാക്കുകൾ `/api/feedback` സെർവർ പ്രവർത്തിക്കുന്ന സമയത്ത് താൽക്കാലിക മെമ്മറിയിൽ / RAM-ൽ മാത്രമാണ് ഉണ്ടാവുക.)
3. **GitHub Official CodeQL & 7-Point Security CI Verification:**
   - ഈ റെപ്പോസിറ്ററിയിലെ കോഡ് GitHub-ന്റെ **CodeQL Security Scanner** (`.github/workflows/codeql.yml`), **7-Point Security & Privacy Audit** (`.github/workflows/security-audit.yml`) എന്നിവ വഴി ഓട്ടോമാറ്റിക്കായി പരിശോധിക്കപ്പെടുന്നു.
